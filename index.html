GoopPlusPlus

A private Discord bot for one Rust team. It connects our Discord server to the game through Rust+, and gathers the music we share into YouTube playlists.

What it does

GoopPlusPlus runs on a small home server and serves a single, invite-only Discord community. It isn't a public bot, so you can't add it to your own server.

  • Rust+ in Discord

    Relays team chat between the game and Discord, and shows server info, map events, smart switches, alarms and storage monitors.

  • Raid alarms

    Members can opt in to hear about in-game alarms by Discord DM, push notification (ntfy) or phone call (Twilio).

  • Team stats

    Tracks per-wipe team stats such as deaths, playtime and sessions, using data from Rust+.

  • AI assistant

    Answers questions about the game and the team's current match in a dedicated channel. The assistant is powered by Anthropic's Claude.

  • Player tracking

    Follows public server and player info from Battlemetrics and Steam.

  • YouTube playlists

    Collects the YouTube links posted in a channel, such as #music, into one unlisted YouTube playlist.

How GoopPlusPlus uses YouTube

Server admins can turn on playlist sync for a Discord channel with the /playlist command. The bot then:

  1. creates an unlisted playlist for that channel and pins its link there,
  2. adds each YouTube video linked in the channel to that playlist, both past links and new ones, and
  3. reads the playlist's contents so it doesn't add the same video twice.

The bot uses the YouTube Data API, signed in to one Google account: the bot operator's own. The playlists belong to that account's YouTube channel. Discord members never sign in with Google, and the bot never sees their Google or YouTube accounts.

The bot only creates and edits the playlists it manages. It doesn't read watch history, subscriptions, comments or any other YouTube data. Nothing it gets from Google is sold, shared, used for ads, or used to train AI models.
