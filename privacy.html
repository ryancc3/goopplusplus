1. Who we are

GoopPlusPlus ("the bot", "we") is a hobby Discord bot built on the open-source rustplusplus project. One person, the operator, runs it for one private Discord server. It isn't a commercial service and isn't available to the public. This policy covers the bot and this website.

2. What the bot collects

The bot only uses information it needs for the features the server has turned on.

InformationWhy
Discord account info: your user ID, username, display name and roles in the server. To respond to commands, check permissions and show who did what.
Messages in the channels the bot is set up to handle (for example the commands, team chat, AI assistant and music channels), plus the slash commands you use. To respond, to relay team chat to and from the game, and to find YouTube links for playlists. The bot doesn't read other channels.
Activity logs: the messages and commands above, with timestamps. For troubleshooting. Logs are saved on the server and also posted to a private log channel in the Discord server.
Rust+ and Steam data: Steam IDs, in-game names, team membership, online status, map position, and death and spawn times as reported by Rust+. It also includes the Rust+ pairing credentials that members choose to register. To show team and server info, send in-game alerts and connect to the Rust server.
Team stats worked out from that game data, such as deaths, playtime, AFK time and sessions, grouped per server wipe. For stat cards and leaderboards in the server.
AI assistant conversations: questions you ask it, a short rolling history per person, and a small shared list of team notes. So the assistant can answer with context. Questions are sent to Anthropic (see section 4).
Alarm notification settings, only if you opt in: whether you want DMs, an ntfy topic, and/or a phone number. To alert you about in-game alarms the way you chose.
Playlist records: the IDs of YouTube videos linked in channels with playlist sync, the IDs of the Discord messages they came from, and the playlist IDs. To add each video once and to show playlist progress.
Text for voice announcements, when voice features are used. Turned into speech by a text-to-speech service (see section 4).

The bot doesn't use cookies, tracking pixels or advertising, and it doesn't collect payment information.

3. Google & YouTube data

The playlist feature uses the YouTube Data API (one of the YouTube API Services). This is the only part of the bot that touches Google user data.

Whose Google account

The bot is signed in to one Google account: the operator's own, through Google's OAuth sign-in. Discord members are never asked to sign in with Google, and the bot never accesses their Google or YouTube accounts.

What it accesses and why

The bot asks for the https://www.googleapis.com/auth/youtube permission ("Manage your YouTube account"), because YouTube requires it to create playlists and add videos. With it, the bot only:

  • creates unlisted playlists on the operator's YouTube channel,
  • adds videos that were linked in Discord to those playlists, and
  • reads the list of videos in those same playlists, so it doesn't add duplicates.

It doesn't read or change anything else, such as watch history, subscriptions, comments, uploads, other playlists or account details.

How it's stored

The sign-in tokens Google issues are stored in a file on the bot's server that only the operator can read. The playlist records described in section 2 are stored on the same server.

How it's shared

Each playlist's link is posted and pinned in the Discord channel it belongs to. The playlists are unlisted, so anyone with the link can view them. Other than that, we don't share, transfer or sell Google user data. We don't use it for advertising, we don't use it to train AI models, and no person reads it except the operator when needed for security, troubleshooting or legal reasons.

GoopPlusPlus's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The bot's access can be revoked at any time from the Google account's security settings page. Access is revoked when that happens, or when the operator retires the feature. Within 7 days after that, the stored tokens and the playlist records described above are deleted from the server. Playlists already on YouTube stay on the operator's channel until the operator deletes them.

By using the YouTube features you agree to the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.

5. Where data is kept

The bot runs on a single private server owned by the operator. Its data, logs and credentials are stored there, not with a cloud provider. Remote access is limited to the operator, and secret files such as tokens and credentials can only be read by the account that runs the bot. No system is perfectly secure, but we take reasonable steps to protect it.

6. How long it's kept

  • Activity logs are size-capped and rotate automatically, so older entries are overwritten. Log messages posted in the Discord log channel stay until deleted there.
  • AI conversation history is capped per person, so older turns drop off. Team notes are capped at a small number and can be removed on request.
  • Alarm notification settings are kept until you turn them off. Turning off every channel deletes your record, including any phone number.
  • Team stats are grouped per wipe and kept for the server's history unless you ask for yours to be removed.
  • Google data is kept as described in section 3.
  • If the bot is shut down for good, its stored data is deleted.

7. Sharing

We don't sell or rent personal information. We only share it with the services in section 4, and only as needed to run the bot. We'd also share it if the law required us to. Other members of the Discord server can see what the bot posts there, including team info, stats, alarm messages and playlist links.

8. Your choices

  • Notifications: you can turn alarm DMs, push notifications and calls on or off yourself at any time.
  • Channels: the bot only reads the channels it's set up for. If you'd rather it didn't handle your messages, don't post in those channels.
  • Access and deletion: you can ask what the bot stores about you, or ask for it to be corrected or deleted. Message the operator on the Discord server, or use the contact link below. We'll respond within 30 days.
  • Google access: see section 3.

9. Children

The bot is only used in a Discord server, and Discord requires users to be at least 13, or older in some countries. The bot isn't directed at children. If we learn that we have data from a child under 13, we'll delete it.

10. This website

This site is hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may log visitor information such as IP addresses, as described in the GitHub Privacy Statement. The fonts load from Google Fonts.

11. Changes

If this policy changes, we'll update it here and change the date at the top. Big changes will also be announced on the Discord server.

12. Contact

To reach the operator, open an issue on GitHub, or message them on the GoopPlusPlus Discord server. GitHub issues are public, so please don't put personal information in one. Just ask to be contacted and we'll follow up privately.
