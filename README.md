# GoopPlusPlus

Home page, privacy policy and terms of service for GoopPlusPlus, a private Discord bot for a Rust team's Discord server.

Live site: https://ryancc3.github.io/goopplusplus/

- [Home](https://ryancc3.github.io/goopplusplus/)
- [Privacy Policy](https://ryancc3.github.io/goopplusplus/privacy.html)
- [Terms of Service](https://ryancc3.github.io/goopplusplus/terms.html)

Questions or data requests: open an issue here, without personal details, and the operator will follow up privately.

Plain static HTML served by GitHub Pages from the `main` branch root. To preview locally:

```
python -m http.server 8420
```
